# Портфолио веб-разработчика — «Хамелеон»

Сайт-портфолио «сайты на заказ». Пока листаешь работы, весь сайт перекрашивается в палитру каждого проекта — так видно, что каждый сайт делается под свой бренд, а не по шаблону. Чистый HTML/CSS/JS, без сборки.

**Живое демо:** https://rootvandal.github.io/portfolio/

## Что внутри

- **Hero** — стопка из трёх окон браузера с настоящими работами: наклоняется за курсором, при наведении сайт в окне листается.
- **Манифест** — текст проявляется по словам при прокрутке.
- **Работы** — у каждой своя сцена: окно браузера и телефон с прокруткой, кнопки «Открыть сайт» и «Попробовать здесь» (живой сайт в окне с переключателем «Компьютер / Планшет / Телефон»).
- **Конфигуратор цены** — тип сайта, число разделов, допы, срочность → расчёт в виде чека и отправка в WhatsApp.
- Процесс, вопросы, контакты, живые часы Алматы и статус «свободен для проектов».

## Запуск локально

```bash
python -m http.server 8804
```

Открыть http://localhost:8804

## Как настроить

Всё — в `config.js`:

- `ME` — ваше имя (`name`; если пусто, в шапке пишется `role` — «Веб-разработчик»), город, статус, телефон, WhatsApp, e-mail, GitHub.
- `WORKS` — работы: `palette` (в какие цвета перекрашивается сайт — палитры в `styles.css`, `body[data-palette=…]`), `live` — ссылка на сайт, `desk` / `mob` — длинные скриншоты в `assets/`.
- `BUILDER` — цены конфигуратора: типы сайтов, цена за раздел, допы, наценка за срочность.
- `STEPS`, `FAQ` — процесс и вопросы.

Скриншоты работ (`assets/*-desk.webp`, `assets/*-mob.webp`) сняты с живых сайтов Playwright'ом. `assets/og.jpg` — превью ссылки для мессенджеров и соцсетей.
