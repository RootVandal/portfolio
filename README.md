# Портфолио веб-студии

Сайт-портфолио: «делаю сайты на заказ» + витрина работ с живыми демо. Чистый HTML/CSS/JS.

**Живое демо:** https://rootvandal.github.io/portfolio/

## Запуск локально

```bash
python -m http.server 8804
```

Открыть http://localhost:8804

## Как настроить под себя

Всё — в `config.js`:

- `ME` — имя/бренд (`name`), ник, роль, город, контакты (WhatsApp, Telegram, телефон, e-mail, Instagram, GitHub). Поменяйте `ME.name` — обновятся шапка, футер, `<title>`.
- `WORKS` — работы. У каждой: `title`, `kind`, `year`, `img` (скриншот в `assets/`), `live` (ссылка на опубликованный сайт — открывается у клиента), `desc`, `tags`.
- `SERVICES`, `STEPS`, `FAQ` — услуги, этапы работы, вопросы.

Скриншоты работ лежат в `assets/` (сделаны с живых сайтов). Чтобы добавить работу — положите скриншот в `assets/` и добавьте объект в `WORKS`.

Форма — демо: собирает сообщение для WhatsApp, на сервер ничего не отправляет.
